# Garber Buick — About Us pages

Static site: `index.html` is the shell (header, nav, video player); each page lives in `assets/*.html` and is loaded by the shell.

- `assets/about.html` — About Us (store-specific)
- `assets/history.html` — Our History (group)
- `assets/community.html` — Community (group)
- `assets/values.html` — Mission, Vision & Values (group)
- `assets/site.css`, `assets/site.js` — styles and the four design-system components
- `assets/*.jpg|webp|mp4` — images and testimonial videos

Deploys automatically to Vercel on push to `main`.
